Notra GEO · engine architecture

Google AI Overview is a SERP, not a model.

Track whether Google’s AI Overview mentions your brand — through SerpApi, on the same scan path as ChatGPT and Claude, without ever storing the rest of the results page.

Why this shape

Cursor and OpenCode are models we prompt. Gemini is a model we prompt. AI Overview is none of that. Google already answered the query on the search results page. We fetch that answer, keep its citations, and hand the text to the existing GEO judge.

Putting it on a parallel product path would fork mention rate, receipts, and gaps. Putting it behind Gemini’s web-search tool would pretend a SERP is an LLM. The catalog already has a slot for non-router engines. That is the slot this uses.

Path through GEO

01

Catalog google/ai-overview is a static Google-provider entry. Gateway serpapi. Visible only when SERPAPI_API_KEY is set. Not a default engine — you turn it on in the picker.

02

Scan dispatch Same planner as every other engine. askEngine pins on gateway serpapi instead of the AI router. No grounded twin, no conversation sequences.

03

SerpApi engine=google with json_restrictor=ai_overview,error,search_metadata. If Google returns a one-minute page_token, follow up with google_ai_overview. Locale follows the prompt language (hl/gl).

04

Judge or absent Overview text is judged for brand mention, position, sentiment, competitors. A recognized missing overview is a stored miss. Malformed SerpApi payloads are engine errors, not visibility misses. Organic results never enter the row.

What is tracked

Keep

  • AI Overview text blocks
  • Overview citations (title, url, domain)
  • The query Google was asked
  • Mention / position / sentiment from the judge

Never store

  • Organic blue links
  • People Also Ask, related searches
  • Knowledge graph, ads, maps
  • SerpApi links or the API key

Activation

Credential Set SERPAPI_API_KEY. The engine is hidden from the catalog while the key is missing.
Project Enable AI Overview under Google in GEO settings. Existing engine selections are unchanged.
Privacy Marked zdr: none. Under enforced ZDR it needs the same explicit approval as Cursor.
